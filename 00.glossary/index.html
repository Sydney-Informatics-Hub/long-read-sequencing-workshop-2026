    Glossary

    Terms used throughout this training, from sequencing hardware through to QC, preprocessing, assembly, polishing, and AMR annotation. Definitions are written to match how each term is actually used in this training's modules, rather than as generic textbook definitions — if you're mid-module and hit an unfamiliar term, this is the place to check first.

    A

    • ABRicate — the tool used in this training to screen assembled contigs for antimicrobial resistance (AMR) genes, here configured to search the NCBI Bacterial Antimicrobial Resistance Gene Database via AMRFinderPlus.
    • Adaptive sampling — ONT's ability to accept or reject individual DNA molecules in real time during sequencing, based on the sequence read so far. Possible because signal decoding happens as sequencing occurs, not afterwards.
    • Adapter — a short synthetic DNA sequence attached to a DNA fragment during library preparation, used to bind the fragment to the flow cell (ONT) or motor protein, or to carry a barcode for later sample identification. Residual adapter sequence in reads is flagged by QC tools and is usually trimmed before assembly.
    • AMRFinderPlus — NCBI's curated database and tool for identifying antimicrobial resistance genes, point mutations, and related genes (virulence, biocide/stress/metal resistance) in a genome assembly, using BLAST and HMMER comparisons against a curated reference set.
    • Antimicrobial resistance (AMR) — when bacteria (or other microbes) no longer respond to the drugs meant to treat them, making infections harder, or impossible, to treat. Detecting AMR genes is a core motivation for sequencing bacterial isolates in a clinical or surveillance setting.
    • Assembly (genome assembly) — the process of reconstructing a genome's sequence from many overlapping sequencing reads, ideally into one closed, circular contig per replicon for a bacterial isolate.

    B

    • Bacterial methylation model — a medaka/Dorado polishing model specifically trained on native bacterial DNA, selected via the --bacteria flag; produces markedly better consensus accuracy than the generic models when polishing bacterial genomes.
    • Barcode / barcoding — a short, kit-specific sequence added to reads during library preparation so multiple samples can be pooled into a single sequencing run and later separated computationally (demultiplexed).
    • BAM — a compressed, binary alignment/sequence file format that basecallers such as Dorado can output, optionally carrying alignment and modified-base information alongside the called sequence.
    • Basecalling — the process of converting the raw electrical signal recorded by a nanopore sequencer (the "squiggle") into an actual A/C/G/T nucleotide sequence, using a neural network.
    • BLAST — a sequence alignment/search algorithm that compares a query sequence against a reference database to find the closest matches; used by AMRFinderPlus, among many other tools, to identify AMR gene hits.
    • Bonito — ONT's research-oriented basecaller, which allows users to train their own basecalling neural networks; superseded by Guppy, and then by Dorado, as ONT's official production basecaller.

    C

    • Chimeric read — a single sequencing read that is actually a fusion of two unrelated DNA fragments, usually a library preparation artefact. Modern assemblers such as Flye typically detect and filter these out automatically.
    • Chopper — the current NanoPack filtering tool, combining the older NanoFilt (length/quality filtering) and NanoLyse (contamination filtering) into a single tool that filters reads by score, length, and contamination level.
    • Circular consensus sequencing (CCS) / HiFi — PacBio's approach of sequencing the same DNA molecule multiple times around a circularised template and combining the passes into one highly accurate consensus read; the basis of PacBio's HiFi reads.
    • Consensus sequence — the "best estimate" final sequence produced by combining information from many individual, error-prone reads aligned to the same region — the output of both assembly and polishing.
    • Contamination — DNA present in a sample that doesn't belong to the target organism, such as host DNA carried over from a cultured isolate, or reagent and environmental contamination. Screened for during QC and removed, in this training, using Minimap2 and Kraken2 against host references.
    • Contig — a contiguous stretch of assembled sequence built from overlapping reads. The goal of bacterial isolate assembly is usually to reduce contig count to one per replicon (chromosome or plasmid) — a "closed" genome.
    • Core (AMRFinderPlus) — the default subset of the AMRFinderPlus database: highly curated, AMR-specific genes and point mutations. Contrast with Plus.
    • Coverage — how many times, on average, each base of the genome has been sequenced (for example, "30x coverage" means each position is covered by roughly 30 reads). A key factor, alongside read length, in whether an assembly will close successfully.
    • Cramino — the NanoPack tool that generates run summary statistics for long-read data, replacing the older, slower NanoStat.

    D

    • Demultiplexing — separating pooled sequencing reads back into their original samples, based on the barcode sequence attached to each read during library preparation.
    • Dorado — ONT's current production basecaller, which has superseded Guppy. Supports POD5 and legacy FAST5 formats, predicts modified bases during basecalling, includes barcode demultiplexing, and — more recently — has gained its own genome polishing capability.
    • Draft assembly — the initial, unpolished genome assembly produced directly from reads, before any consensus polishing has been applied to correct remaining errors.
    • Duplex read — an ONT read generated by sequencing both strands of the same DNA molecule and cross-validating them against each other, giving substantially higher accuracy (over 99.9% with current chemistry) than a single-strand (simplex) read.

    E

    • Efflux pump — a membrane-embedded protein pump that some bacteria use to actively expel antibiotics (and other compounds) from the cell, lowering the effective drug concentration inside. One of the main mechanisms of antibiotic resistance.
    • Error rate — the proportion of bases in a read that are incorrect compared with the true sequence. A defining difference between short- and long-read platforms, though the gap has narrowed substantially with current-generation chemistries.
    • ESBL (extended-spectrum β-lactamase) — a class of bacterial enzymes able to break down a broad range of β-lactam antibiotics, including some last-resort options, making ESBL-producing bacteria a significant clinical problem.

    F

    • FAST5 — the legacy Oxford Nanopore raw signal file format, superseded by the more compact and efficient POD5 format.
    • FASTQ — a plain-text file format storing both a read's sequence and a per-base quality score for each base; the standard input format for most downstream long-read analysis tools, including assemblers.
    • fastplong — a fast, general-purpose long-read preprocessing tool supporting quality filtering, length filtering, adapter trimming, and sliding-window quality trimming, among other options.
    • FastQC — a widely used short-read QC tool that also runs on long-read data, reporting sequence quality, content, GC content, duplication levels, and overrepresented sequences. Lacks several long-read-specific metrics that NanoPlot provides.
    • Filtlong — a long-read filtering tool that selects a "better" subset of reads based on a combined score of read length and read identity/quality.
    • Flongle — a small, low-cost, single-use ONT flow cell adapter, suited to quick or low-yield sequencing runs.
    • Flow cell — the physical device in which sequencing takes place. For ONT devices, it houses the nanopore sensors, motor proteins, and sequencing chemistry; MinION flow cells are compatible with both the MinION and GridION instruments, while PromethION uses its own larger-format flow cells, in configurations of up to 24 or 48 depending on the instrument model.
    • Flye — the long-read genome assembler used in this training. Specifically expects coverage above 10x and an N90 read length over 1 kb, and generally doesn't require preprocessed reads, since it filters chimeric reads and bad ends automatically.

    G

    • GC content — the proportion of a DNA sequence made up of guanine (G) and cytosine (C) bases. Used as a QC signal, since an unusual GC distribution across reads can point to contamination or library bias.
    • Genotype vs phenotype — the distinction between having a gene with the potential to cause a trait (genotype — e.g. carrying an AMR gene) and actually expressing that trait (phenotype — e.g. being clinically resistant to an antibiotic). AMR gene detection tools report genotype, not a guaranteed phenotype.
    • GridION — an ONT benchtop sequencer, essentially five MinIONs combined into one unit, running five flow cells in parallel.
    • Guppy — ONT's former production basecaller, which replaced Bonito and was itself later replaced by Dorado.

    H

    • HAC (High Accuracy) basecalling — one of ONT's three basecalling models, offering a middle ground between speed (Fast) and accuracy (SUP). Compatible with real-time basecalling on GridION and PromethION devices with sufficient compute.
    • HiFi — see Circular consensus sequencing.
    • HMM / HMMER — Hidden Markov Model-based sequence search method. AMRFinderPlus uses HMMER, alongside BLAST, to identify AMR gene hits, including distant relatives of known gene families that fall below the threshold for a BLAST hit.
    • Horizontal gene transfer — the movement of genetic material (such as an AMR gene) between bacteria by means other than direct reproduction, often via mobile elements like plasmids. A key reason resistance genes can spread rapidly through a bacterial population.
    • Hybrid assembly — a genome assembly strategy that combines both long and short reads, using long reads to resolve structure and repeats, and short reads to polish base-level accuracy.

    I

    • Indel — an insertion or deletion of one or more bases relative to a reference sequence. A common structural variant type that long reads are much better than short reads at detecting reliably.

    K

    • K-mer — a substring of length k extracted from a sequencing read; used by some QC and classification tools (including FastQC's k-mer content analysis) to spot biases or patterns not obvious from single-base statistics.
    • Kraken2 — a taxonomic classification tool used in this training's QC pipeline to identify and remove host DNA contamination (e.g. human or cow sequence) from bacterial isolate reads, using the Kalamari database.

    L

    • Library preparation — the wet-lab process of preparing extracted DNA for sequencing, including fragmenting (if needed), attaching adapters and/or barcodes, and, for ONT, attaching the motor protein that feeds DNA through the nanopore.
    • Long-read sequencing (LRS) — sequencing technology (chiefly ONT and PacBio) that reads native DNA molecules many kilobases long in a single pass, as opposed to short-read platforms that sequence in fragments of a few hundred base pairs.

    M

    • medaka — ONT's neural-network-based consensus polishing tool, which corrects a draft assembly using a pileup of reads aligned against it. Specifically trained to work well on drafts from the Flye assembler.
    • Minimap2 — a fast, general-purpose long-read aligner, used in this training both for aligning reads during polishing and for screening out host DNA during QC.
    • MinION — Oxford Nanopore's original pocket-sized sequencer, released in 2016, running a single flow cell from a laptop's USB port — the device most responsible for making sequencing portable.
    • MinKNOW — ONT's device-control software, which records the raw signal from a sequencing run, organises it into individual reads, and can also perform live basecalling.
    • Motor protein — the protein attached to a nanopore that ratchets a single DNA (or RNA) strand through the pore, base by base, during ONT sequencing.
    • MultiQC — a tool that aggregates QC reports (such as many individual FastQC reports) from multiple samples into a single, comparable summary report.

    N

    • N50 — the read (or contig) length at which the cumulative length of all reads/contigs at or above that length equals 50% of the total. A more informative way of summarising a variable-length dataset than a simple mean; used for both raw reads and assembly contiguity.
    • Nanopore — the tiny protein pore, embedded in an ONT flow cell membrane, through which a single DNA or RNA strand passes. Changes in the electrical current as bases pass through the pore are what get decoded into a sequence.
    • NanoPack / NanoPack2 — a suite of long-read QC and data-processing tools, including NanoPlot, Chopper, and Cramino. NanoPack2 is the current generation of the suite.
    • NanoPlot — the primary long-read QC tool used in this training, part of the NanoPack suite, reporting long-read-specific statistics such as N50 that short-read tools like FastQC don't provide.

    O

    • ONT (Oxford Nanopore Technologies) — the long-read sequencing company and platform used throughout this training, known for portable devices (MinION, GridION, PromethION, Flongle) and real-time nanopore sequencing.
    • Overrepresented sequence — a sequence that makes up an unusually large share of a sample's reads. FastQC flags any sequence above 0.1% of total reads, since this can indicate contamination, low library diversity, or a genuinely biologically significant sequence.

    P

    • PacBio (Pacific Biosciences) — one of the two dominant long-read sequencing platforms, known for shorter but very high-accuracy reads via its HiFi/circular consensus sequencing approach, as an alternative to ONT.
    • Phred score / quality score (Q score) — a logarithmic measure of confidence in an individual base call, where a higher score means a lower expected error probability. Q20 corresponds to 99% accuracy (1 error in 100 bases), and Q30 to 99.9% accuracy (1 error in 1,000 bases).
    • Pilon — a short-read genome polishing tool, commonly used as a final polishing step after long-read assembly and polishing, to correct remaining base-level errors using short-read data.
    • Plasmid — a small, typically circular piece of DNA, separate from the main bacterial chromosome, that can replicate independently and is often the vehicle by which AMR genes move between bacteria via horizontal gene transfer.
    • Plus (AMRFinderPlus) — the optional, non-default subset of the AMRFinderPlus database, covering genes related to biocide/stress resistance, general efflux, virulence, or antigenicity. Only searched when the --plus option is used.
    • Point mutation — a change to a single base in a DNA sequence. Some point mutations are known to cause antimicrobial resistance and can specifically be screened for by AMRFinderPlus when an --organism option is supplied.
    • Polishing — the process of correcting remaining base-level errors in a draft genome assembly by aligning reads back against it and generating a refined consensus sequence, typically using a tool such as medaka (for long reads) or Pilon (for short reads).
    • POD5 — Oxford Nanopore's current raw signal file format, more compact and efficient than the legacy FAST5 format it replaced.
    • Porechop — a tool focused specifically on detecting and trimming adapter sequences from ONT reads.
    • Preprocessing — the optional step, between QC and assembly, of trimming and/or filtering reads based on length, quality, or contamination. Treated as genuinely optional for long-read bacterial isolate assembly with modern assemblers, unlike short-read pipelines, where it's close to mandatory.
    • PromethION — ONT's highest-throughput sequencing platform, running many flow cells in parallel (up to 24 or 48, depending on the instrument model) for large-scale sequencing projects.
    • pycoQC — a comprehensive, interactive HTML-based QC tool for ONT data, covering read quality, length, coverage, active channels, and quality over the course of a run.

    Q

    • Q score — see Phred score.
    • QC (quality control) — the process of assessing, and if needed acting on, the quality of sequencing data before proceeding to downstream analysis. The essential first step of any sequencing workflow.

    R

    • R10.4.1 — the current generation of ONT flow cell chemistry, underpinning "Q20" sequencing, with single-read accuracy exceeding 99%.
    • Racon — a long-read polishing tool, commonly used for an initial round (or several rounds) of long-read polishing before a final round with medaka and, ultimately, short-read polishing.
    • Remora — an ONT tool that adds nucleotide modification (e.g. methylation) calling on top of standard basecalling.

    S

    • Short-read sequencing — sequencing technology (e.g. Illumina) that produces reads a few hundred base pairs long. Contrasted throughout this training with long-read sequencing (ONT/PacBio), and used here specifically as a source of high base-level accuracy for polishing long-read assemblies.
    • Simplex read — an ONT read generated from a single strand of a DNA molecule, as opposed to a duplex read, where both strands are sequenced and cross-validated.
    • Squiggle — the informal term for the raw electrical current signal recorded as a DNA or RNA strand passes through a nanopore, before it has been decoded into a base sequence by basecalling.
    • SUP (Super Accurate) basecalling — ONT's most accurate, most computationally intensive basecalling model, recommended for de novo assembly projects and therefore the default choice for bacterial isolate WGS.

    T

    • Tn5 transposase — an enzyme used in some sequencing library preparation kits to fragment and tag DNA in one step; its insertion preferences can introduce sequencing bias against GC-poor regions.
    • Trimming — removing unwanted sequence (such as adapters, barcodes, or low-quality bases) from the ends of a read, as distinct from filtering, which removes whole reads.

    V

    • Variant calling — identifying positions where a sequence differs from a reference. medaka can perform variant calling as well as consensus polishing, depending on which model is selected.

    W

    • Whole-genome sequencing (WGS) — sequencing intended to capture the complete genome of an organism — in this training, a single bacterial isolate — as opposed to sequencing only a marker gene or a mixed community sample.
