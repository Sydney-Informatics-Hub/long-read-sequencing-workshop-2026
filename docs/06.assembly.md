# Lesson 6 - *De novo* bacterial genome assembly

!!! hint "Learning objectives"

    - Explain the goals of *de novo* genome assembly from long reads
    - Use tools like `flye` to perform *de novo* bacterial genome assembly

## 6.1 Introduction to *de novo* genome assembly

### Talking points

- How genome assembly works: finding overlaps between reads, assembling large contigs
- Goal for bacterial genome assembly: assembling complete, circular contigs
    - One large contig (chromosome) + possibly several smaller contigs (plasmids)

## 6.2 *De novo* assembly tools

### Talking points

- Tools available: flye, raven, canu, etc.
- Explore tool options, typical run commands
    - Can have tabbed section to give options/commands for multiple tools
    - Focus on flye for actual workshop
- Explore tool outputs and statistics

## 6.3 Exercise

### Tasks

- Run your assigned FASTQ through `flye` and assemble your first bacterial genome
- Inspect the output files and answer the following questions:
    - How many contigs were assembled?
    - How long was the largest contig?
    - How long was the smallest contig?
    - Were there any potential plasmids in your sample?
    - Were all the contigs circular? If not, why might that be?
