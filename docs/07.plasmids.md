# Lesson 7 - *De novo* plasmid assembly

!!! hint "Learning objectives"

    - Explain the limitations of tools like `flye` for reconstructing plasmid sequences
    - Use specialised tools like `plassembler` to perform *de novo* assembly of plasmids from long reads

## 7.1 Introduction to plasmid detection

### Talking points

- What plasmids are and why they're important
- Challenges with plasmid assembly and why some assemblers miss them

## 7.2 Plasmid detection tools

### Talking points

- Tools available: plassembler
- Explore tool inputs
    - Relies on flye assemblies to know what has already been assembled
        - Plassembler can run flye itself, or you can provide a pre-made flye assembly
- Explore tool outputs, metrics, statistics

## 7.3 Exercise

### Tasks

- Run 'plassembler' using your assigned FASTQ and the flye assembly you generated in 06.assembly.md
- Inspect the outputs and answer the following questions:
    - Did plassembler detect any additional contigs in your sample? If so:
        - How many?
        - Were they all circular or were some linear?
- If additional plasmids/contigs were detected, add them to your assembly FASTA (use `cat` to concatenate the FASTA files)
    - Link to advanced exercise: 08.consensus.md: use 'autocycler' to create a consensus assembly from flye + plassembler + optional other assemblies
