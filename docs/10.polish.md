# Lesson 10 - Assembly polishing

!!! hint "Learning objectives"

    - Explain the need for polishing a long read assembly
    - Use tools like `medaka` to polish a long read assembly

## 10.1 Why we need to polish long read assemblies

### Talking points

- Long read sequences are still less accurate than short read sequences
- Long read assemblies will frequently have errors, especially around homopolymers - homopolymer lengths can be hard to properly call from long read data
- Approaches to polishing:
    - Long read-only methods: attempt to correct errors solely based on the long read sequencing data
    - Short read polishing: additional short read sequencing can complement the long read assemblies to correct errors

## 10.2 Long read polishing tools

### Talking points

- Tools available for long read polishing:
    - `medaka`: uses machine learning/deep learning to correct errors
    - `racon`
- Explore tool inputs, options, and outputs
    - Focus on `medaka`, but can have `racon` information as well (tabbed section)

## 10.3 Exercises

### Tasks

- Run your *de novo* assembly through `medaka` to polish the genome
- Run `dnadiff` to compare the pre- and post-polish assemblies
- Inspect the outputs and answer the following questions:
    - How did the contig lengths change after polishing?
    - How many corrections did `medaka` make?
    - What was the most frequent correction it made?
